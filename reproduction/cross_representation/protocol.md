# Matched quadratic interaction study

This is an exploratory extension on two datasets previously used in HSMT. The analysis choices below were written before reading the new DINOv2 classification results. There is no external preregistration.

* Use the ten archived outer DTD splits with exact-duplicate exclusions and the four KTH-TIPS2-b splits by physical specimen. Join the two representations by original image identifiers and use precisely the same outer training and test lists, labels and class ordering. Test images contribute to neither scaling nor fitting. DTD and KTH carry separate estimands. GTOS and GTOS-mobile are outside this analysis.
* Use each full RGB image bicubically resized to 224 by 224. Keep the archived HSMT extraction and fold-specific preprocessing. Use the same frozen DINOv2 ViT-S/14 checkpoint as HSMT. From transformer blocks 3, 6 and 12 (indices 2, 5 and 11), apply the model's final LayerNorm to each output and average the 256 patch tokens. Exclude the class token. For each layer, use each training feature mean and population standard deviation with a floor of 0.0001. Clip standardized values to [-12,12] and L2-normalize each image separately, leaving zero vectors zero. Retain the final-layer CLS for a single-block control. Use floating-point inference without autocast.
* The three weights are each one third, the common kernel divisor is 3.25 and the ridge penalty is 1. Refit using one-hot targets centred on the training class proportions and add the training proportions back at prediction. Use the HSMT kernels L, L+S, L+X and Q. For the primary analysis use the native kernel scale. Q minus L+S is the incremental change in macro-recall after adding cross-products. The main comparison is the difference of these changes, DINOv2 minus HSMT, in percentage points. The HSMT historical profile is used only to check reproduction. Compare the direct contrast on the paired classifications for the same test images or groups.
* For the two primary comparisons, use 95% simultaneous Bonferroni intervals across the DTD and KTH contrasts (two 97.5% marginal intervals), conditional on the fitted classifiers. Also report per-dataset pointwise 95% intervals for both gains and for the direct contrast. For DTD use the archived group multiplier implementation (repeated appearances of an image and recognised exact duplicates receive the same sign). For KTH resample whole physical specimens within material, four per material. Use seed 19112026 and 100,000 draws. No margin for equivalence or practical superiority is specified. Also report per-class recalls and corrected/introduced errors. No hypothesis about a numerical direction is required to proceed.
* Descriptive sensitivities comprise the fixed-penalty unit-diagonal comparison and the secondary Q minus L+X contrast. Single-block DINOv2 controls use either the mean patch or CLS of block 12 with the same preprocessing, linear coefficient 2/3.25 and ridge 1. The uncentred unit-length CLS with its raw linear kernel and ridge 1 separately checks the historical DTD full-field CLS decisions. No grid, layer or cohort is selected from test scores.
* For the separate regularization sensitivity keep equal weights and retain the native scale. Select the ridge penalty separately for L+S and Q from the existing archive order (1, 0.1, 10, 0.01, 100, 0.001) by mean inner macro-recall on its archived validation splits. Use the first maximum. Relearn all supervised-fit training statistics within each inner split and refit the selected model on the full retained outer training set. The per-corpus sensitivity intervals are pointwise.
