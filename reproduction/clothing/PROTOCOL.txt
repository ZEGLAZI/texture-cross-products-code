Repeated validation on the previously inspected clothing-pattern cohort
Oussama ZEGLAZI and Mohammed Rziza | 19 November 2026

Purpose. Estimate how often the DTD-derived square kernel beats the cross-product kernel under new partitions of the fixed 211 photographic sources. Previous scores on this cohort are known. This specification precedes computing scores on the 30 new partitions. These are repeated test assignments of an existing cohort, not an independent collection.

Population. Identical image keys, crop pixels and six labels as in the corrected 211-source archive. Never replace an image. Require uniqueness of all keys and equality of sample count, labels, pixel dimensions and ordering for every method. Freeze a SHA-256 digest for every decoded RGB crop. Treat an original photograph as the sampling unit. Product or garment identity across different photographs is unknown.

Evaluation. Use 30 seeds, from 2026111900 through 2026111929 inclusive. For each, StratifiedKFold(5, shuffle=True, random_state=seed), scikit-learn 1.8.0, applied to the existing key order. For outer test fold k, validate on (k+1) mod 5. Fit on the remaining three folds, select by validation macro recall then refit on all four non-test folds. No test image enters normalization or tuning. Each image receives exactly one out-of-fold prediction per repeat and method. Average the six whole-repeat class recalls, then average repeats equally. Do not average five unequal folds' class recalls or count multiple appearances as new images.

Representations. Apply the frozen HSMT kernels to F7, F8 and RGB. The square kernel keeps the common linear term and uses the individual squared base similarities. The cross-product kernel has the same linear term and uses the three inter-block products. For the internal additive reference retain the historical linear kernel and common divisor. Use the same four channel-weight profiles and six ridge penalties as the earlier comparison. Profiles, penalties and deterministic tie order are stored in code/frozen/protocol.json. For all methods use the same prior-centred ridge classifier. For single-reference kernels only the same six penalties are applicable. Use the same 224 by 224 whole crop in every extractor.

Published references. Joint grayscale CLBP S/M/C, P=24 and R=3, 1352-bin histogram, square-root L1-normalized (Guo et al., IEEE TIP 2010, DOI 10.1109/TIP.2010.2044957). Frozen official DINOv2 ViT-S/14 without registers, L2-normalized 384-dimensional class token, cosine kernel (Oquab et al., arXiv:2304.07193), no fine-tuning. Reuse the same extractors and checkpoint as the manuscript's DTD comparisons.

Additional readout. Use the arithmetic mean of the DINO cosine and each unit-diagonal-normalized HSMT kernel (squares or additive). Divide by sqrt(Kii*Kjj); if a diagonal entry vanishes use zero. Calculate each feature norm with the scale fitted on the corresponding training set only. Fixed one-half mixing. Four profiles and six penalties, validation as above. Compare the two hybrids to establish whether any increment over DINO is specific to the square terms. No learned mixture.

Contrasts. Primary = squares minus crosses. Secondary family = squares minus additive, squares minus CLBP, squares minus DINO, DINO+squares minus DINO, DINO+squares minus DINO+additive. Report all contrasts and win/tie/loss counts on the 30 paired partitions. Primary 95% paired percentile interval, resampling image identities within each class, keeping all 30 predictions per image together, 100000 draws, PCG64 seed 19112647. Report nominal 95% and family-adjusted 99% intervals for each of five secondary contrasts (Bonferroni). These intervals are conditional on fitted models and the six classes. Use the complete repeat range to show partition sensitivity. Report recall by class descriptively, without significance claims. Treat 30 repeats as sensitivity on 211 sources. Positive primary mean alone is insufficient; interpret the conditional interval and the partition range together. No result-based stopping.
