# Frozen supervised CNN comparison

This follow-up was specified after the colour–texture and DINOv2 scores on DTD, KTH-TIPS2-b and FMD-to-Lytro transfer were available and before extracting or scoring the new CNN. The three evaluation settings have been inspected before. The follow-up repeats the original design using one previously untested encoder.

Use only TorchVision ResNet-50 (ImageNet-1K supervised V2, checkpoint SHA-256 11ad3fa62ca79e40addfd354a8ec4b7c75143b3038b8d2a807fbc68deab379ca), frozen in evaluation mode. Take the output after the last residual unit of layer2, layer3 and layer4. Average each channel over all spatial positions (512, 1024, 2048 dimensions). Keep native channel counts and FP32 features. Match the original full-field bicubic 224-pixel image, RGB mean and standard deviation, folds, identities, equal block weights, block standardization and clipping, square and full KRR, source validation rule, six-penalty grid and tie order. Do not evaluate alternative checkpoints, stages or pooling using these labels.

Primary family of six new contrasts: on each of DTD, KTH and Lytro, (1) ResNet full-minus-square macro-recall gain at lambda=1 on the native scale and (2) the change, from fixed to separately validated penalties, in the ResNet gain minus the handcrafted gain. Use 95% paired Bonferroni intervals across these six, conditional on the fitted models. Follow the original test-unit design: identity/duplicate groups spanning all DTD test appearances, physical specimens within material on KTH, captures within material in Lytro. Report mean gain, both absolute recalls, pointwise intervals and all selected penalties. Keep training-mean diagonal matching as a sensitivity. Use a secondary six-comparison family for direct ResNet-minus-DINOv2 differences of incremental gains under the native fixed and selected regimes on each dataset. Report any direction. Do not pool or interpret significance differences between corpora as direct tests.

Repeat the existing external paired source/target bootstrap using its exact 999 indexed draws, six penalties and FMD source roles. Relearn all preprocessing, selection and final models for the new encoder, then pair the resulting ResNet gains with the existing same-draw handcrafted/DINOv2 scores. Give an exploratory pointwise percentile interval for the selected-minus-fixed ResNet-minus-handcrafted shift. Verify unresampled labels and literal repeated-row fits on the first two draws.

Release feature and image hashes, split-level validation scores, paired decisions, source code, all bootstrap draws and replay checks. No fine tuning. Differences between CNN and transformer bundle architecture, pretraining, feature dimension and the locations of the extracted layers.
