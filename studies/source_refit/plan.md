# Source and target resampling for cross-acquisition recognition
The point estimates and selected penalties from the original FMD to Lytro transfer were known before this analysis. This is a follow-up, decided before computing any of the following resamples. The proposed descriptor, frozen DINOv2 encoder, RGB histogram, original 500/500 FMD split roles and six-value grid are unchanged.
Primary quantity T = (DINO full-minus-square gain minus colour-texture full-minus-square gain) under separate source validation minus the same difference at fixed lambda = 1. Units are percentage points of target macro recall. Use 999 preallocated paired stratified nonparametric bootstrap replicates, seed 20261121. Draw the original number of FMD images with replacement within each material and source fit/validation role independently. Draw target captures with replacement within each material independently of source; pair all models within a replicate. Learn every normalization on each replicate's training fold, reselect each model's penalty using source validation, refit on the pooled resampled FMD and compute the target contrast. Keep train/validation and source/target identities disjoint. Report the original T, the 2.5 and 97.5 percentile endpoints for the single primary T and the fraction of replicates where four choices are all one. Retain all draws and penalty frequencies. The percentile interval describes this resampling design conditional on the source role assignment, ten material categories, original collections and frozen representations. Treat other contrasts as descriptive. Use deterministic draw IDs and verify directly against literal duplicate-row fitting on trial resamples. Compare zero resampling to archived decisions. No new search over blocks or corpora.
